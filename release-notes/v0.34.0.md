Easier first runs on macOS and Windows, updates that finish by themselves, and a link to these notes after every update.

**Updates finish by themselves**

After Install update, Fontelle now restarts by itself onto the new version and reopens your song, so the update is never left waiting. It waits instead while there is anything a restart could lose: unsaved changes, playback, recording, an export, a shared song, or a question on screen. Once those are done, it restarts.

From the next update on, the first start menu of a new version says which version it is, with a What's new button that opens these notes.

**macOS: a proper app**

The macOS download is now `Fontelle.app`, which opens with a double-click. Fontelle isn't signed with a paid Apple developer account, so macOS asks you to confirm it once. The download includes `FIRST-RUN.txt` with the steps. After the first open, updates keep it opening without asking again. Move it to your Applications folder first: an app opened from Downloads runs from a temporary copy that can't update itself, and Fontelle tells you so.

**Windows: no console window**

Fontelle no longer opens a black console window behind the studio, and closing that window no longer closes Fontelle. The programs Fontelle runs in the background, such as the update check, don't flash windows of their own either.

**The install count**

Fontelle sends one anonymous ping a day so we can count installs. It now goes during your first session, about a minute after the notice that says so, instead of waiting for a second launch.

It now also says how far people get: firsts like a first song saved or a first plugin loaded, and which parts of Fontelle were used that day (the mixer, the piano roll, export and so on). These are fixed words chosen in advance, never names, files, notes or anything from your songs. Settings ▸ Count this install turns all of it off, and the details are at https://fopull.com/privacy#install-ping.

**Supporting Fontelle**

From your fifth launch, the start menu shows one line about supporting Fontelle, with a link. After an update it can show again, at most once a month.
