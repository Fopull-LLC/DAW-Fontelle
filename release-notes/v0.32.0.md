Everything new since 0.31.0: LV2 plugins on Windows and macOS, clearer panels over see-through themes, and four themes redrawn.

**LV2 plugins on Windows and macOS**

LV2 plugins now load on Windows and macOS as well as Linux. Fontelle looks for them where their installers put them:

- Windows: `C:\Program Files\Common Files\LV2` and `%APPDATA%\LV2`
- macOS: `/Library/Audio/Plug-Ins/LV2` and `~/Library/Audio/Plug-Ins/LV2`

You can also add your own folders, as for the other formats. A song made on Linux with an LV2 plugin opens on Windows or macOS with that plugin's Windows or Mac version.

A plugin's own window opens when it has one made for that system. Plugins whose window is built with Qt or GTK (drumkv1, Calf and others) get Fontelle's panel of controls instead on Windows and macOS.

Most LV2 plugins are made for Linux first, so expect fewer of them on Windows and macOS than CLAP or VST3. On a Mac, LV2 has only been tried by our automated tests so far.

On Linux, LV2 support is now built into Fontelle, so the download no longer needs lilv installed.

**Themes**

- Lo-fi Rain is redrawn, Nebula has new colours, and Sunroom and Midnight are touched up.
- With a see-through theme, the panels drawn over the studio let the clips behind show through their words. The share panel, the progress card, questions, the save prompt, track options and DisgustingBeat's menu now have solid backgrounds.

**Fixed**

- **Messages at the bottom of the window** sometimes vanished before you could read them. They now stay for a few seconds.
- **Changes made in an LV2 plugin's own window** now mark the song as unsaved, and in a shared song they reach everyone else. Before, you could close the song without being asked to save them, and the others never heard them.
- **The start menu's Recover button** had no words on it. It now says what it recovers.
